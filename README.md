# ENSO Monitor

Application web d'exploration de l'indice ONI (NOAA) pour suivre les épisodes El Niño et La Niña.

## Prérequis

- Python 3.12
- Node.js 22
- Docker et Docker Compose v2
- Git

## Configuration

Copier le modèle de variables d'environnement puis renseigner un mot de passe :

    cp .env.example .env
